# Phase 13 Screenshot Matrix

## Fixture and steps

The Playwright test `renders dense responsive Workspace Knowledge results and
provenance` creates a temporary Workspace, then inserts a fixed derived-index
fixture after the application has applied migration 0009. The fixture contains one
paper page, one code range, one Research Question, and one confirmed Paper-Code
Link. All four contain the query `clipping`. It contains no real Zotero Library,
PDF, repository, credentials, network request, or paid provider.

Steps are: launch Electron -> create Workspace -> open Knowledge -> capture the
unindexed keyword-only state -> restart with the fixed index -> search `clipping`
-> select the paper result -> verify citation -> resize and capture. The test also
asserts `scrollWidth <= clientWidth` at each standard viewport.
