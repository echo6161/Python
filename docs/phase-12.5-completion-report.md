## Architecture and ownership

This phase is Renderer-only except for the Vite build configuration. It adds no database migration,
IPC channel, preload capability, filesystem access, network access, or external write operation. The
dashboard calls the existing typed `window.paperMind` domain APIs. Zotero remains authoritative for
bibliography/PDF data and Git remains authoritative for source code.

PaperMind still cannot embed a Zotero-owned PDF in the Workspace because no bounded Zotero attachment
stream exists in the current bridge. The UI therefore reports real PDF availability and retains the
controlled external open flow rather than displaying a simulated reader.
